# 角色别名

## 来源与范围

核对日期：2026-10-21。

- [BWIKI 角色图鉴](https://wiki.biligame.com/pcr/角色图鉴)：读取每个角色卡片的编号、名称与外号。
- [BWIKI 角色别称](https://wiki.biligame.com/pcr/角色别称)：补充短别称。该页面注明来自花舞攻略组；感谢页面贡献者维护。
- 角色编号同时核对对应头像的单位编号，以及本次部署环境的游戏静态角色名单。

随插件分发的 `pcr_wiki_aliases.json` 覆盖292个角色，包含1222条名称/别称事实。相对0.2.4的静态词库，新增786个规范化后的名称/别称，包括此前缺失角色和换装版本的完整名字。上述数字是本次核对快照，不表示收录了所有服务器、所有未来角色或全部民间叫法。

只收集短名称对应关系，不收录网站正文、外号由来、攻略或图片。机器人查询时只读本地词库，不临时访问 BWIKI；游戏角色名单更新不会自动下载新的外号。

## 使用

```text
怎么拆 els AMS 蚊子 小虎 布丁
怎么拆春剑黄骑AMS蚊子布丁
怎么拆 春剑 黄骑 小虎 水m 布丁
```

`els`、`ELS`、`ＥＬＳ`均对应厄里斯（1290），不是公主凯露（1806）。`AMS`对应爱梅斯（1230），`水m`对应空花（夏日）（1270）。角色名允许中英文括号和全半角混用。

裸外号不自动扩展到所有换装：普通茉莉的“小虎”与万圣茉莉的“万圣跳跳虎”是不同角色。较长名字优先匹配，全名优先于可能撞名的别称。相同角色使用两个外号仍是同一个角色，不能借外号绕过阵容重复检查。

空格明确分开角色：`初音 栞 布丁 黄骑 小虎`是五个独立角色，不会合并成双人角色。双人角色可写`星栞`或完整的`初音、栞`并与其他角色用空格分开。带符号的别称也建议独立书写，例如`tp+3 布丁 黄骑 小虎 AMS`。

## 冲突处理

新增外号若在来源中指向多个角色，不根据网页顺序或最近使用记录随便分配。`xcw`、`nnk`、`水猫`等已有外号保留0.2.4的明确映射；`泥头车`、`能天使`等没有既有唯一映射的冲突项不新增，请使用全名。

过短的单个英文字母不作为新外号导入；数字别称保留经校验的唯一映射，例如`512`对应矛依未（新年）。

旧别称表中夏日镜华/夏日未奏希/夏日美美的部分编号与头像不符，这些行不导入，采用图鉴中一致的记录。缺少可验证头像编号的行也不凭名称猜编号。

爱梅斯、涅比亚、花凛、兰法、美空的已知旧剧情NPC编号会在加载时迁移到可用角色编号。迁移仅对明确的“旧编号＋名称”组合生效，不把其他NPC或任意同名输入强制替换。

## 维护约定

修改词库时应保留来源与日期，先检查编号与头像一致，再检测规范化外号冲突。不要把相同外号同时分配给多个角色，也不要用猜测的拼音首字母批量生成外号。新外号必须覆盖独立解析、连写、换装长名称、旧缓存重载和真实QQ权限回归测试。发布包必须包含根目录的 `pcr_wiki_aliases.json`。
